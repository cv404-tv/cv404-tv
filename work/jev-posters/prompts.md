# 海报抽象画面提示词

工具：内置 imagegen；四张画面分别生成，再由 HTML/CSS 排版准确中文和二维码。

1. **决策之核**：在洋红与浅蓝粒子云画面中央，以 `outputs/geometric-mark/geometric-mark.svg` 为准确几何参考，将原三角锥替换为上下错开的交织几何模块。保留 SVG 的外轮廓、比例、开口和上下分离关系，表现为有明显厚度、投影的黑色石材，正面与侧面同材质、无彩色面层；保留周围云雾与光束。
2. **漂浮窗口**：TypeSafe 官网复古桌面视觉的原创演绎。几扇无字半透明系统窗口漂浮于粉蓝云雾，少量像素 glider，左上深色留标题空间，无文字、标志或二维码。
3. **分岔绸带**：米白背景上的红色雕塑绸带从一个黑色节点分成三路，少量像素网格，高级艺术摄影质感，左上留标题空间，无文字、标志或二维码。
4. **孔版之眼**：黄色、粉色、黑色孔版印刷拼贴，巨大的同心圆眼睛围绕红色方块，粗糙纸张与套印偏差，左上留标题空间，无文字、标志或二维码。

共同约束：画面为海报背景层，最后的中文、报名信息和二维码由 HTML/CSS 叠加，避免生成图中文字失真。
